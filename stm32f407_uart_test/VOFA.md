# 钢球平衡 PID · VOFA+ 在线调参手册

本手册适用于当前带 `brake_speed_gain` 的 F407 固件。MODE1 居中、MODE2 三点保持和 MODE3 抗扰恢复共用一组 RAM 参数。先看 VOFA+ 右侧的数据列表。当前固件会出现 I0～I18，刚复位时 I18 默认是 0.90。若新建页面后只收到 I0～I17，先核对板上固件版本。

使用 USB 转 3.3 V TTL 模块连接电脑和 F407 的 USART1。K230 的视觉串口使用 PD8/PD9。

| USB转TTL | STM32F407VET6 |
| --- | --- |
| RX | PA9 / USART1 TX |
| TX | PA10 / USART1 RX |
| GND | GND |

板子正常供电时不用连接TTL模块的VCC。选择3.3V TTL电平。

## 需要更新固件时

当前固件位于工程的 `stm32f407_uart_test/Firmware/F407_K230_Center_Balance.hex`。STM32CubeProgrammer 可通过 ST-LINK 的 SWD 接口下载并校验。每次重编译会更新这个 HEX。在 PowerShell 中执行下列命令即可编译。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File 'D:\steel_ball\h_balance\tools\build_center.ps1' -Keil 'D:\Keil_v5\UV4\UV4.exe'
```

下载器接 **SWDIO → PA13、SWCLK → PA14、GND → GND**。写入成功后，复位会自动跑启动行程。复位前先取出球并将机构放在机械下端。

## VOFA+ 设置

1. 接口选 **串口**，选择设备管理器中 USB 转 TTL 模块对应的 COM。设置 **115200、8N1、无流控**，关闭 DTR、RTS 和 Break，再连接。
2. 接收协议选 **JustFloat**。右侧出现 I0～I18 后，用一张波形图看 I0/I1，用另一张看 I2/I3。若波形图使用手动采样间隔，将 Δt 设为 **50 ms**。精确计时用带时间戳的记录或录像。
3. 发送区选 **Str/ASCII** 并追加实际换行（LF 或 CR）。停住闭环后，记下 I18 的原值，再发送 `brake_speed_gain=0.40`。看到 **I6 为 1 且 I18 变为 0.40** 就表示写入成功。发回原值即可恢复。小数使用点号。
4. 常用命令可加到左侧命令列表。绑定数值控件时可用 Str 模板 `brake_speed_gain=%f\n`，以实际发出的字节为准。 [VOFA+ 命令绑定](https://www.vofa.plus/docs/learning/start/data_cmd_parameter/)

固件通常每 50 ms 发送一帧，每帧包含 19 个小端 float32 和四字节帧尾 `00 00 80 7F`。命令执行结果和参数值在数据通道中回读。 [VOFA+ JustFloat 格式](https://www.vofa.plus/docs/learning/dataengines/justfloat/)

| 通道（从0开始） | 含义 |
| --- | --- |
| 0 | 最近收到的钢球位置，mm |
| 1 | 最近收到的钢球速度，mm/s |
| 2 | F407 已发送的累计 STEP 步数 |
| 3 | 电机目标步数 |
| 4 | 状态：0上电/调平，1等球，2纠偏，3稳定保持，4人工停止，5故障 |
| 5 | 观测有效：1有效，0丢球/过期，只有为1时通道0/1才代表当前有效观测 |
| 6 | 最近命令结果。0 尚无结果，1 成功，−1 命令或参数错误，−2 串口接收错误 |
| 7～18 | 参数回读，逐项对应关系见下表 |

## 参数命令与当前固件默认值

```text
kp=0.50
kv=0.70
ki=0.60
gain=1.50
brake=2.00
max_speed=20
accel=10
ref_accel=120
kff=0
kff2=0
max_offset=150
brake_speed_gain=0.90
```

每行是一个独立命令，回车/换行后生效，也可一次发送多行。不支持通过该串口启动电机、修改方向、写Flash等命令。

| 通道 | 命令名 | 默认值 | 调节什么 |
| --- | --- | ---: | --- |
| I7 | `kp` | 0.50 | 球离目标越远，位置纠偏越强 |
| I8 | `kv` | 0.70 | 对目标球速与实测球速之差的反馈，影响加速和制动 |
| I9 | `ki` | 0.60 | 学习维持平衡所需姿态的速度 |
| I10 | `gain` | 1.50 | 动态纠偏和后续学习的整体倍率 |
| I11 | `brake` | 2.00 | 提前制动时的速度反馈倍率 |
| I12 | `max_speed` | 20 | 目标球速上限，mm/s |
| I13 | `accel` | 10 | 规划回中减速的加速度，mm/s²，也参与 MODE3 边缘制动预估 |
| I14 | `ref_accel` | 120 | 目标球速的爬升速度，mm/s² |
| I15 | `kff` | 0 | 线性速度补偿 |
| I16 | `kff2` | 0 | 带方向的平方速度补偿 |
| I17 | `max_offset` | 150 | 相对当前参考姿态的总纠偏幅度上限，步 |
| I18 | `brake_speed_gain` | 0.90 | 球越快接近当前目标，越早进入制动区，额外的反向阻尼越大。设为 0 时只使用基础制动 |

VOFA 和 SWD 调参脚本均接受有限的 32 位浮点数。`accel` 必须大于 0。`max_speed`、`ref_accel`、`max_offset` 和 `brake_speed_gain` 接受零和正数。电机最终目标受 0～650 步行程限制。

未知参数、NaN/Inf 和多余内容均拒绝修改。命令过长、接收错误或半条命令超时后，会丢弃到下一次换行，再接收完整的新命令。收发使用独立缓冲，发送队列满时跳过整帧，不阻塞稳球循环。

在线修改立即生效，复位会恢复 `Core/Src/center_balance.c` 中的编译默认值。找到合适数值后，写入该文件的 `g_balance_tuning`，重新编译、烧录即可固化。

MODE3 的 `accel` 也影响边缘制动的预估触发距离，`max_offset` 限制最大制动姿态。修改这两个值后应重新核对两侧制动距离。

固件的位置误差是「目标位置减去钢球位置」。P 项是 `kp × 位置误差`，速度项是 `kv × (目标球速 − 实测球速)`，I 项是慢慢学到的姿态补偿。速度项在目标球速接近 0 时主要负责阻尼，离目标较远时还会推动球接近目标球速。调参使用 `kv` 这个命令名。

## 单独调速度制动增益

1. 在 MODE1 居中下记录 I18 当前值。每轮从零点同侧、相同距离放球，先测约 25～30 mm 起点，再用较远的同侧起点观察更快回中时的变化。只比较 I5 有效、起点条件一致的记录。
2. 保持本轮的 `brake`、`accel`、`kv` 和 `max_speed` 固定。如果 I1 在 I0 过零前仍较大，可从默认 0.90 试到 1.00，确认 I6 为 1、I18 为写入值。比较过零速度、过零后的最大偏差和进入稳定区的用时。
3. 如果球在离目标较远时明显提前掉速，回中时间变长，可从默认 0.90 试到 0.80。要看基础制动的表现，做一轮 `brake_speed_gain=0` 的对照。最后用留下的数值复测另一侧。
4. 同时看 I2 和 I3。如果目标步数已经反向而已发步数长期跟不上，先检查电机和驱动。I18 是你写入的增益，制动效果要从位置、速度及电机目标曲线判断。

附加制动量随**朝向目标的速度**增加。以 I18＝0.90 为例，朝目标移动速度为 30 mm/s 时，固件把制动距离估算乘以 1.45，并在制动区增加一项反向速度反馈。这个倍率用于计算触发距离，实机刹停还取决于管道倾角、电机响应和限幅。MODE3 的 `EDGE BRAKE` 有自己的边缘保护逻辑，`accel` 参与边缘距离估算。

## 其他台架调参

1. **先确认观测和电机跟踪。** 选 MODE1，球在物理零刻度时检查 I0 约为 0，静止时 I1 约为 0，I5 应为 1。用小位移核对球速方向。I2 是主控发出的 STEP 累计数，I3 是目标步数。I3 在变而 I2 长时间追不上时，先查电机脉冲节奏；若 I2 已跟上而管道没有对应动作，先查驱动器、机构和间隙。
2. **从默认值测一次。** 在相同安装角度，从零点两侧各约 25～30 mm 放球，对比进入误差带的用时、过零峰值、静止偏差和 I2/I3 的跟踪。每轮只改一个参数，做好同侧同起点的对照，再复测另一侧。回退时发回上一轮的数值。
3. **按波形选择要试的参数。** 下表数值是相对本版默认值的小步试探。先在台架确认效果，再应用到赛程。

| 波形或现象 | 优先尝试 |
| --- | --- |
| I0 过零后反复摆动，I1 在过零时速度仍高，I2 能跟上 I3 | 先单独试 I18。若回中全程都太快，再小幅降低 `max_speed`，复查回中用时 |
| 回中缓慢、基本不过零，方向正确、I2 跟得上 I3，且目标步数尚未碰限幅 | 可试 `kp=0.55`，比较同一起点的回中时间和过零峰值 |
| 初始动作急，反向时 I3 经常拉开与 I2 的距离 | 先试 `ref_accel=100`，让目标球速爬升慢一些 |
| 远处球静止，I5 持续为 1，方向正确，I3 缓慢变化且未达到输出限幅 | 检查姿态学习和驱动力。若累积确实太慢，可单独试 `ki=1.0`；I3 卡在限幅时增加积分无效 |
| I0 始终偏在一侧，球放到物理零刻度时画面仍显示偏移 | 先校正 K230 毫米零点及管道倾斜时的刻度映射 |
| I5 掉到 0，或小球静止时 I0/I1 明显跳动 | 先排查识别丢帧、光照和标定。旧的 I0/I1 读数不能用来判断闭环是否缺力 |

第一轮先保留 `gain=1.50`、`brake=2.00`、`kff=0` 和 `kff2=0` 作对照。`gain` 同时改变动态纠偏和学习速率，`kv` 同时改变速度误差驱动和阻尼。

## 用比赛模式复测

| 模式 | 怎么操作 | 记录什么 |
| --- | --- | --- |
| MODE1 居中 | SW3 确认后从左右各放球一次 | 进入零点附近的用时、过零峰值、静止偏差 |
| MODE2 三点保持 | SW3 确认，按题目把球放在 O 点 ±5 mm 内。确认后第一帧有效坐标自动启动 | I0 依次到 −50、+50、0 mm。实测每段进入最终保持区间的用时、每点是否连续 1.8 s 保持 ±8 mm，以及全程用时。用 7 s 和 30 s 对照题目要求 |
| MODE3 抗扰恢复 | SW3 确认，等 `PUSH BALL` 后把球推离 O 点 25～35 mm，静止至少 0.8 s 后释放 | 按录像中的实际释放时刻计时，核对 6 s 内进入 ±12 mm、6～8 s 保持 ±8 mm。两侧分别复测边缘制动和峰值位置 |

每轮记录模式、起点、改动前后参数、用时、最大误差和是否丢球。调好后保存 I7～I18 的实测参数。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 没有任何波形 | 检查 F407 上电、COM 选择、PA9 → TTL RX、GND 共地和 JustFloat。若 COM 被其他串口工具打开，先关闭该工具 |
| 有波形，发送后 I6 和参数值都保持原样 | 检查 TTL TX → PA10 和发送模式。命令末尾要发实际的 LF 或 CR。启用追加换行时，发送框只填 `名称=数值` |
| I6 为 −1 | 检查参数名、数值和固件版本。发生半条命令超时后，先发一个空换行，再重发完整命令 |
| I6 为 −2 | 检查串口接收错误，确认 115200、8N1、共地和信号连接，再发一个空换行并重试 |
| I5 为 0 | F407 收到无效观测，或超过 180 ms 没有新鲜的有效观测。检查 K230 识别和视觉串口 |

## 自适应姿态补偿

自检结束只把当前位置当成起始参考，不假定它水平。球距离目标至少10 mm，且朝目标的速度不超过4 mm/s（包括静止或向外滚），持续约0.3 s、且未处于制动时，开始慢速学习姿态补偿。球正常回中或制动时保留已有补偿；零点附近保留低速学习。过零不会缩小或清除补偿。

补偿以输出步数独立保存。`ki=0` 冻结后续学习，已经学到的姿态补偿仍然生效。修改 `gain` 只影响动态纠偏和后续学习。人工停止或丢球时保持实际步数并保留所学补偿。需要停止电机时使用 K230 的返回键。

`ki` 控制姿态补偿的累加速度，积分使用的误差最多取 10 mm。闭环允许学习且未在制动时，球离目标至少 10 mm、球速绝对值不超过 4 mm/s 并持续约 0.20 s，即以 5.5 倍速率累加补偿。偏差至少 4 mm 且小于 10 mm 时，静止约 0.30 s 后按 3 倍速率补偿。球速超过 4 mm/s 后退出快速补偿，保留已累加的步数。默认 `ki=0.6`、`gain=1.5` 时，偏差至少 10 mm 的未饱和静止补偿上限约 49.5 步/s。在 VOFA+ 上用 I1 找到球开始滚动的时刻，用 I3 观察起滚前的目标步数斜率。

|x|≤2 mm、|v|≤4 mm/s持续约0.3 s，且电机已追上目标后，进入S3，把当时完整的实际保持输出转移到新的参考姿态，并将增量积分归零；转移前后目标步数相同。偏差达到4 mm或球速达到10 mm/s时恢复纠偏，参考仍是学到的姿态。不会强制返回310步。

`max_offset` 限制的是起始/最近稳定参考姿态周围的总纠偏量（动态输出加学习补偿），积分自身也有同样限幅。触及此幅度或0～650步机械边界时停止同向积分，反向积分仍可退出；电机指令计步明显落后时也不继续向落后方向增加积分。不存在靠移动参考来绕开饱和的逻辑。初始捕获时所需平衡姿态和瞬态制动余量必须在这些限幅允许的范围内，才可能完成回中。

球远处停滞时 I3 应逐步变化，稳定后 I2/I3 保持学到的步数。I2 表示已发送的 STEP 计数。

原理、适用边界和可复现的验证结果见 [CONTROL.md](CONTROL.md)。

随工程提供的 HEX 已核对 12 个编译默认值。手册中的试调数值用于台架对照，实际制动距离和比赛计时以台架测量为准。
