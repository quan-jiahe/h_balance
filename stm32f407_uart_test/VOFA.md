# 钢球平衡 PID · VOFA+ 在线调参手册

本手册适用于以 `03d9cd1` 为基础的本地在线调参版，覆盖 MODE1 居中、MODE2 三点保持和 MODE3 抗扰恢复。三个模式共用同一组 RAM 参数。直接使用 `03d9cd1` 的原始 HEX 时，参数写入返回 `I6=-3`。要调参，请烧录本地 `codex/f407-vofa-live-tuning` 的 HEX 或按下文重新编译下载。

使用 USB 转 3.3V TTL 模块，电脑通过模块连接 F407 的 USART1。当前用沁恒模块的 CMSIS-DAP 接口烧录。K230 继续使用 USART3 的 PD8/PD9。

| USB转TTL | STM32F407VET6 |
| --- | --- |
| RX | PA9 / USART1 TX |
| TX | PA10 / USART1 RX |
| GND | GND |

板子正常供电时不用连接TTL模块的VCC。选择3.3V TTL电平。

## 烧录

在 `C:\Users\LENOVO\Desktop\ultra\h_balance` 的 PowerShell 中执行：

```powershell
.\stm32f407_uart_test\flash_center.ps1
```

该脚本使用本机Keil的CMSIS-DAP下载器：先重新编译居中目标，同时更新AXF和发布HEX，再下载并检查校验结果、复位开始原上电行程。默认Keil路径为 `D:\keil5\core\UV4\UV4.exe`，可用 `-Keil` 指定其他路径；不再调用仅面向ST-Link的CubeProgrammer命令。只检查模块和驱动可运行 `./stm32f407_uart_test/flash_center.ps1 -Check`，不会连接目标MCU或烧录。

沁恒一体模块的RX/TX只负责VOFA通信。烧录还需 **SWDIO→PA13、SWCLK→PA14、GND→GND**。工程已配置CMSIS-DAP、SWD 100 kHz和STM32F407VE的512 KB Flash算法。烧录前退出Keil调试，将机构置于机械下端并取出球。

共享uvoptx明确关闭 **Settings → Pack → Debug Description → Enable**，使用常规CMSIS-DAP驱动连接和原Flash算法。此前省略此设置时Keil启用了DFP的 `DebugDeviceUnlock → CheckID`，实机报 `0xE00FFFE8` 读取失败。修改后保留编程校验；若Keil已打开工程，需关闭再重开以加载新配置。配置已修正，尚未验证修正后的实机下载；若仍不能访问目标，检查SWD接线、供电和复位线，而不是继续改平衡参数。

若COM串口正常而“WCH CMSIS-DAP”显示错误码28，缺少的是调试接口驱动。到[沁恒官方WCH-LinkUtility页面](https://www.wch.cn/downloads/WCH-LinkUtility_ZIP.html)下载并解压，用管理员权限安装 `Drv_Link/WCHLinkDrv_WHQL_S.exe`，然后重新插拔模块。不要用CH340驱动替代，也不要更换串口接口的驱动。驱动安装后，Keil中Debug应显示CMSIS-DAP Debugger，目标选择F407_K230_Center_Balance。

## VOFA+ 设置

1. 接口选串口及TTL模块对应COM，115200、8位数据、无校验、1位停止位，无流控。
2. 接收协议选择 **JustFloat**。关闭 DTR、RTS 和 Break。连接后用两张波形图分别观察 I0/I1 和 I2/I3，避免电机步数的量程压缩球的位置波形。
3. 参数指令用 **Str/ASCII** 模式并启用自动追加换行。验证写参时，先在 K230 点返回停止，记录 I8 当前值。若当前值是默认的 `0.70`，可发送 `kv=0.72`，核对 I6 变为 `1`、I8 变为 `0.72`，再发 `kv=0.70` 恢复。发送框需要实际的 LF 或 CR，别在普通文本发送框里输入两个字符 `\n`。
4. 滑块、输入框或按钮可绑定 `kp=%f\n`、`kv=%f\n` 等模板。小数使用点号。

设备每50 ms发送一帧，18个小端float32和四字节帧尾 `00 00 80 7F`。同一串口不混发ASCII回显，命令结果和参数当前值在数据通道中查看。

| 通道（从0开始） | 含义 |
| --- | --- |
| 0 | 最近收到的钢球位置，mm |
| 1 | 最近收到的钢球速度，mm/s |
| 2 | F407 已发送的累计 STEP 步数 |
| 3 | 电机目标步数 |
| 4 | 状态：0上电/调平，1等球，2纠偏，3稳定保持，4人工停止，5故障 |
| 5 | 观测有效：1有效，0丢球/过期，只有为1时通道0/1才代表当前有效观测 |
| 6 | 最近命令结果：0尚无命令，1成功，-1命令/参数错误，-2串口接收错误，-3旧固件锁定写入 |
| 7～17 | 参数回读，逐项对应关系见下表 |

## 参数命令与当前固件默认值

```text
kp=0.50
kv=0.70
ki=0.875
gain=1.50
brake=1.60
max_speed=30
accel=40
ref_accel=120
kff=0
kff2=0
max_offset=150
```

每行是一个独立命令，回车/换行后生效，也可一次发送多行。不支持通过该串口启动电机、修改方向、写Flash等命令。

| 通道 | 命令名 | 默认值 | 接收范围 | 调节什么 |
| --- | --- | ---: | --- | --- |
| I7 | `kp` | 0.50 | 0～3 | 球离目标越远，位置纠偏越强 |
| I8 | `kv` | 0.70 | 0～4 | 对目标球速与实测球速之差的反馈，影响加速和制动 |
| I9 | `ki` | 0.875 | 0～3 | 学习维持平衡所需姿态的速度 |
| I10 | `gain` | 1.50 | 0～3 | 动态纠偏和后续学习的整体倍率 |
| I11 | `brake` | 1.60 | 1～4 | 提前制动时的速度反馈倍率 |
| I12 | `max_speed` | 30 | 1～150 mm/s | 目标球速上限 |
| I13 | `accel` | 40 | 1～300 mm/s² | 规划回中减速的加速度，也参与 MODE3 边缘制动预估 |
| I14 | `ref_accel` | 120 | 1～500 mm/s² | 目标球速的爬升速度 |
| I15 | `kff` | 0 | −3～3 | 线性速度补偿 |
| I16 | `kff2` | 0 | −0.05～0.05 | 带方向的平方速度补偿 |
| I17 | `max_offset` | 150 | 1～300 步 | 相对当前参考姿态的总纠偏幅度上限 |

未知参数、NaN/Inf、超范围值和多余内容均拒绝修改。命令过长、接收错误或半条命令超时后，会丢弃到下一次换行，再接收完整的新命令。收发使用独立缓冲，发送队列满时跳过整帧，不阻塞稳球循环。

在线修改立即影响RAM参数，复位恢复 `Core/Src/center_balance.c` 的默认值。找到合适数值后把参数写回该文件、编译烧录以永久保存。本次保留用户已修改的默认 `kp=0.5`。

MODE3 的 `accel` 也影响边缘制动的预估触发距离，`max_offset` 限制最大制动姿态。修改这两个值后应重新核对两侧制动距离。

固件的位置误差是「目标位置减去钢球位置」。P 项是 `kp × 位置误差`，速度项是 `kv × (目标球速 − 实测球速)`，I 项是慢慢学到的姿态补偿。速度项在目标球速接近 0 时主要负责阻尼，离目标较远时还会推动球接近目标球速。调参使用 `kv` 这个命令名。

## 台架调参顺序

1. **先确认观测和电机跟踪。** 选 MODE1，球在物理零刻度时检查 I0 约为 0，静止时 I1 约为 0，I5 应为 1。用小位移核对球速方向。I2 是主控发出的 STEP 累计数，I3 是目标步数。I3 在变而 I2 长时间追不上时，先查电机脉冲节奏；若 I2 已跟上而管道没有对应动作，先查驱动器、机构和间隙。
2. **从默认值测一次。** 在相同安装角度，从零点两侧各约 25～30 mm 放球，对比进入误差带的用时、过零峰值、静止偏差和 I2/I3 的跟踪。每轮只改一个参数，做好同侧同起点的对照，再复测另一侧。回退时发回上一轮的数值。
3. **按波形选择要试的参数。** 下表数值是相对本版默认值的小步试探。先在台架确认效果，再应用到赛程。

| 波形或现象 | 优先尝试 |
| --- | --- |
| I0 过零后反复摆动，I1 在过零时速度仍高，I2 能跟上 I3 | 先试 `max_speed=25`。仍过冲时，可单独试 `kv=0.75`，同时复查出发速度和回中用时 |
| 回中缓慢、基本不过零，方向正确、I2 跟得上 I3，且目标步数尚未碰限幅 | 可试 `kp=0.55`，比较同一起点的回中时间和过零峰值 |
| 初始动作急，反向时 I3 经常拉开与 I2 的距离 | 先试 `ref_accel=100`，让目标球速爬升慢一些 |
| 远处球静止，I5 持续为 1，方向正确，I3 缓慢变化且未达到输出限幅 | 检查姿态学习和驱动力。若累积确实太慢，可单独试 `ki=1.0`；I3 卡在限幅时增加积分无效 |
| I0 始终偏在一侧，球放到物理零刻度时画面仍显示偏移 | 先校正 K230 毫米零点及管道倾斜时的刻度映射 |
| I5 掉到 0，或小球静止时 I0/I1 明显跳动 | 先排查识别丢帧、光照和标定。旧的 I0/I1 读数不能用来判断闭环是否缺力 |

第一轮先保留 `gain=1.50`、`brake=1.60`、`kff=0` 和 `kff2=0` 作对照。`gain` 同时改变动态纠偏和学习速率，`kv` 同时改变速度误差驱动和阻尼。

## 用比赛模式复测

| 模式 | 怎么操作 | 记录什么 |
| --- | --- | --- |
| MODE1 居中 | SW3 确认后从左右各放球一次 | 进入零点附近的用时、过零峰值、静止偏差 |
| MODE2 三点保持 | SW3 确认，按题目把球放在 O 点 ±5 mm 内。确认后第一帧有效坐标自动启动 | I0 依次到 −50、+50、0 mm。实测每段进入最终保持区间的用时、每点是否连续 1.8 s 保持 ±8 mm，以及全程用时。用 7 s 和 30 s 对照题目要求 |
| MODE3 抗扰恢复 | SW3 确认，等 `PUSH BALL` 后把球推离 O 点 25～35 mm，静止至少 0.8 s 后释放 | 按录像中的实际释放时刻计时，核对 6 s 内进入 ±12 mm、6～8 s 保持 ±8 mm。两侧分别复测边缘制动和峰值位置 |

每轮记录模式、起点、改动前后参数、用时、最大误差、是否丢球和是否触发制动。调好后先记下 I7～I17 的实测参数，再改回 `Core/Src/center_balance.c` 中的 `g_balance_tuning` 并重新编译烧录，以便复位后继续使用。

## 自适应姿态补偿

自检结束只把当前位置当成起始参考，不假定它水平。球距离目标至少10 mm，且朝目标的速度不超过4 mm/s（包括静止或向外滚），持续约0.3 s、且未处于制动时，开始慢速学习姿态补偿。球正常回中或制动时保留已有补偿；零点附近保留低速学习。过零不会缩小或清除补偿。

补偿以输出步数独立保存。`ki=0` 冻结后续学习，已经学到的姿态补偿仍然生效。修改 `gain` 只影响动态纠偏和后续学习。人工停止或丢球时保持实际步数并保留所学补偿。需要停止电机时使用 K230 的返回键。

`ki` 控制累加速度。积分使用的误差最多取10 mm，因此远处静止时，每秒最多增加约 `10 × ki × gain` 步的输出。例如 `ki=0.3`、`gain=1.5` 时约4.5步/s；默认 `ki=0.875`、`gain=1.5` 时约13.1步/s。这些是未限幅时的指令变化率，不是实测倾角或电机反馈。

|x|≤2 mm、|v|≤4 mm/s持续约0.3 s，且电机已追上目标后，进入S3，把当时完整的实际保持输出转移到新的参考姿态，并将增量积分归零；转移前后目标步数相同。偏差达到4 mm或球速达到10 mm/s时恢复纠偏，参考仍是学到的姿态。不会强制返回310步。

`max_offset` 限制的是起始/最近稳定参考姿态周围的总纠偏量（动态输出加学习补偿），积分自身也有同样限幅。触及此幅度或0～650步机械边界时停止同向积分，反向积分仍可退出；电机指令计步明显落后时也不继续向落后方向增加积分。不存在靠移动参考来绕开饱和的逻辑。初始捕获时所需平衡姿态和瞬态制动余量必须在这些限幅允许的范围内，才可能完成回中。

观察 I0/I1、I2/I3和I4/I5：球远处停滞时I3应逐步变化，正常回中时制动，稳定后I2/I3保持学到的步数。I2仍只是已发STEP计数，不是编码器反馈。所有18个通道及11个参数命令的顺序保持不变。

原理、适用边界和可复现的验证结果见 [CONTROL.md](CONTROL.md)。

此前已在 COM17 实收旧固件的 18 通道数据。本地在线调参版已通过 Keil 编译和 419 项 Cortex-M 仿真检查。手册中的试调数值用于台架对照，实机写参和控制表现需要现场确认。
